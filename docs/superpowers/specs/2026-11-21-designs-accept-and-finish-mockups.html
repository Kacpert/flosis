AI usage and cost per organization

Flosis runs Claude in many places (task conversations, PR reviews, estimates, agents, Designs, bug analysis), but nothing about those runs is saved, so we can't say what an organization, a project or a single run cost. We're moving to billing by token usage… Invoicing and payments are the next ticket.

Designs · Open the designs · merge commit 9f3c2a1NEW

- New (11): Admin › Configuration — AI costs hidden for everyone, Consumption — this month, all time, no plan, over the limit, Profile Settings — costs off for everyone · Flosis admin › Models & prices, Organizations, Flosis Sp. z o.o. — cost and price, Plans, New plan

- Updated (10): Admin › Bug Reporting, Configuration — AI, Create Tasks, AI PR Reviews, AI Agents & Alerts, AI Estimate, Profile Settings (+3 states)

- Through shared components: sidebar, chat panel, pipeline header, process header and 5 more

Two amounts

- Cost: what the provider reports the run cost (not calculated from the price list). Visible to Flosis admin only.

- Price: cost + the plan's margin (e.g. cost €10, margin 30% → price €13). This is what the organization sees and what counts toward its limit. The organization never sees the margin.CHANGED

Cost of a single item

Shown on the item itself: the total so far, e.g. “€12”. The month goes in brackets only when it differs: “€12 (€3.23 this month)”, or “€12 (none this month)”.CHANGED

Display

- Light and minimal: small, muted text that doesn't compete with the content, on a row that's already there, never a line of its own.CHANGED

Configuration → Consumption (organization admins only)CHANGED
